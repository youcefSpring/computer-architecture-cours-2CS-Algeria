# هندسة الحواسيب — درس كامل باللغة العربية

مقياس **UEF31: Architecture des ordinateurs** (الأرصدة 5، المعامل 3).
درس بصيغة **A4** مكتوب بـ LaTeX، بشرح مبسط خطوة بخطوة، ومخططات، وبرامج بلغة التجميع مشروحة سطرًا سطرًا.

الأستاذ: د. بن عبد الرزاق يوسف

## المحتوى (`Computer_Architecture.pdf`)

| الفصل | الموضوع |
|:---:|---|
| 1 | التنظيم العام للوحدة المركزية: التاريخ، المكونات، فون نيومان وهارفارد، الذاكرة، الحافلات |
| 2 | البنية الداخلية للمعالج: السجلات، وحدة الحساب والمنطق (المجمّعات، الأعلام)، وحدة التحكم، التعليمات، أنماط العنونة، دورة التعليمة |
| 3 | المعالج Intel 8086: السجلات، العنونة المقطعية، كل أصناف التعليمات، لغة الآلة، الإدخال والإخراج، المكدس، الإجراءات، المقاطعات |
| 4 | المعالجات ذات 32 و64 بتًا: IA-32 و AMD64، السجلات، العنونة المسطحة، SSE و AVX، خط الأنابيب |
| 5 | المعالجات الحديثة: الأنوية المتعددة وقانون Amdahl، الذاكرة المخبئية وتسلسل الذاكرة |
| ملاحق | ملخص تعليمات 8086، الفروق بين EMU8086 و NASM، قاموس عربي–فرنسي–إنجليزي |

كل فصل ينتهي بتمارين محلولة.

## البرامج (`code/`)

- `code/ch2`, `code/ch3`: برامج 8086 بصيغة **EMU8086** (ملفات `.COM`، تبدأ بـ `org 100h`).
- `code/ch4`: برامج x86-64 و 32 بتًا بصيغة **NASM** لنظام Linux، وبرامج C (SSE، AVX، ومخرجات `gcc -S`).
- `code/ch5`: تجارب بلغة C (زمن الوصول إلى الذاكرة، المحلية، الخيوط).

كل البرامج **نُفذت فعلًا**:
- برامج 8086 جُمّعت بـ GNU as ونُفذت في محاكي Unicorn (مع محاكاة `int 21h`). الملفات `.out` هي ما يظهر على الشاشة،
  و`.lst` هي لغة الآلة، و`.trace` هي قيم السجلات بعد كل تعليمة (منها أُخذت جداول التتبع في الدرس).
- برامج الفصلين 4 و5 نُفذت على حاسوب بمعالج Intel Core i7-8665U، والأرقام في الدرس هي نتائج هذا التنفيذ.

لتنفيذ برنامج 64 بتًا:

```bash
nasm -f elf64 hello64.asm && ld hello64.o -o hello64 && ./hello64
```

## الترجمة (Compilation)

```bash
cd tex && tectonic -o .. main.tex && mv ../main.pdf ../Computer_Architecture.pdf
```

- `tex/style.tex`: التنسيق المشترك (الألوان، الصناديق، كتابة الشيفرة).
- `tex/ch1.tex` … `tex/ch5.tex`, `tex/appendix.tex`: الفصول.
- `fonts/`: الخطوط (Amiri و AlBattar).
